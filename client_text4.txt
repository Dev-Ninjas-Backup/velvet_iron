Hi team! 
I finished another round of testing the latest APK, and overall the app is looking really good! There has been a huge improvement, and most of the features I tested are now working beautifully, including exercise logging. Thank you for all the work you've put into these updates. I just have a few remaining fixes/questions: 
1. BARCODE SCANNER – DEFAULT SERVING When scanning a food, it currently defaults to 100 mL. Could we please have it default to 1 serving instead? Most users will log food by serving, and they can adjust the quantity from there if needed. 
2. BARCODE SCANNER – FOOD NOT LOGGING After scanning a food and pressing Save, the item does not get added to the food log/daily calorie and macro totals. It should be added to the appropriate meal and reflected in the daily totals after saving. 
3. STEP JOURNEY DESTINATION The Grand Journey currently says: "77,253 / 1,000,000 steps to The World's Edge" The destination should be The Shattered Citadel, not The World's Edge. Please update this anywhere else World's Edge appears as the destination. 
4. ONBOARDING – FOOD Please add an N/A/Skip option for food during onboarding. Some users may not have eaten yet or may want to finish onboarding without logging food immediately. 
5. ONBOARDING – MEDICATIONS Please add an N/A/"I don't take medications" option during onboarding. Not every user takes medication, so this should not be required to complete onboarding. 
6. DEFAULT MEDICATION QUEST "Elixir of the Alchemist – Log your GLP-1 medication" should not be a mandatory/default Codex quest. Not every user takes a GLP-1 or medication, so users should not be unable to complete their normal daily quests/XP because this doesn't apply to them. Medication/shot tracking could instead be an optional quest users can add or enable for themselves.
7. PUSH NOTIFICATIONS Do we currently have push notifications implemented? If not, I would like at least one daily notification encouraging users to return to the app/check in with their companion. For example: "Your companion is waiting for you. Return to the Codex to continue today's journey." Eventually it would be great for users to control notifications in Settings, but for V1 I mainly want to know what notification functionality is currently implemented and what is feasible before launch. 
8. GUILD HALL / DISCORD ACCESS I saw that Guild Hall (Discord Community) has been added to Settings, which looks great! Could you please explain how Discord access is currently intended to work? The private Discord community is included with the user's subscription, so ideally Guild Hall should only provide access to users with an active subscription/trial. I also want to understand what happens if someone's subscription expires or is cancelled. Is there currently a mechanism for verifying an active subscription and restricting/removing Discord access when the user is no longer subscribed, or would we need a separate Discord bot/integration for that? 
9. PROFILE PICTURES I know the profile picture updates are already being worked on, so I am just waiting for those updates and don't have anything additional to add there right now. Everything else I tested appears to be working as expected. The app is looking really good, and I am very happy with how much this build has improved. Thank you again for all of the work you've put into it!
